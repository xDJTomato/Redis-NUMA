# Legacy upstream files

These files were carried over unmodified from upstream `redis/redis` and are
kept here only for historical provenance. They are not maintained and do not
describe this project (Redis-NUMA):

- `00-RELEASENOTES` — upstream Redis's historical per-version release notes
- `MANIFESTO` — antirez's original Redis design philosophy
- `BUGS` — points to the upstream `redis/redis` issue tracker
- `INSTALL` — points to the upstream Redis website

For this project's actual build/test/architecture docs, see the repo root
`README.md`, `ARCHITECTURE.md`, `TESTING.md`, and `docs/new/`.
